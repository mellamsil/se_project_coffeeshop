# Coffee Shop - Responsive Landing Page

A fully responsive, multi-section coffee shop landing page built with semantic HTML5 and modular CSS3 following the Flat BEM methodology. The project emphasizes accessibility, responsive layout design, multimedia integration, and clean front-end architecture aligned with design specifications.

## Project Overview

The Coffee Shop Website was developed as part of a front-end web development learning track to demonstrate mastery of semantic HTML, responsive layouts, and UI/UX consistency.
It replicates a realistic client project scenario, focusing on precise layout implementation, typography, and interaction effects derived from a Figma design brief.

## Project features

- _Responsive Multi-Section Design_ – Built with a mobile-first approach using Flexbox and Grid, ensuring full responsiveness across devices with no horizontal scrolling.
- _Semantic HTML & Accessibility_ – Structured with HTML5 elements (header, nav, main, section, footer) to improve readability, SEO, and accessibility compliance.
- _Interactive Navigation & UI Elements_ – Smooth anchor-based scrolling, hover and active states, and subtle CSS transitions enhance user interaction and engagement.
- _Consistent Visual Design_ – Integrated Google Fonts, a cohesive color palette, and spacing aligned with the Figma design brief to create a polished, professional layout.
- _Engaging Media Integration_ – Embedded optimized images and video elements to enrich visual storytelling and showcase the brand’s atmosphere.
- Contact Form Functionality\* – Designed an accessible, user-friendly contact form with proper labeling, placeholders, and validation attributes.
- _Clean, Scalable Code Architecture_ – Applied Flat BEM methodology for modular CSS organization, Prettier formatting, and Git version control to maintain consistency and scalability.
- _Optimized Performance & SEO_ – Included meta tags, viewport settings, and W3C-validated HTML/CSS to ensure fast loading and modern web standards compliance.

## Technologies Used

- Languages: HTML5, CSS3
- Methodology: Flat BEM
- Layout Systems: Flexbox, CSS Grid
- Design Tools: Figma
- Version Control: Git, GitHub
- Formatting Tools: Prettier
- Validation: W3C HTML & CSS Validator
